# 20 · whatever

Author: RITA · Started: 2026-11-02 · Status: sketch · Stack: static HTML + JS

A first page for RITA's sketch, with synthetic wind only. It asks: When weather is shown to you in real time, what is measured, what is guessed, and who decides which is which?

## Run

Online, once published: `https://ritawangruiting.github.io/weather-commons/20-whatever/`

On your computer:

```bash
cd sketches/20-whatever
python -m http.server 8000
```

Then open http://localhost:8000.

## 1. Event

Which weather event, practice or intervention is this about? When and where did it happen, and who was involved?

## 2. Simulate

What does the model or visualization calculate? What goes in, what rules does it follow, and what comes out?

## 3. Situate

Where does it sit in the world: places, infrastructure, institutions, history, politics?

## 4. Narrate

The story in a few sentences. What can a viewer learn here, and what should they not conclude?

## Sources and limits

For every dataset: who made it, which version and date, when you downloaded it, its licence, and what you changed. Say whether each layer is observed, reanalysed, modelled, synthetic or interpretive. Then say what this sketch cannot show.

- Wind field in `index.html`: synthetic. A steady east wind with random spread, written by hand for the starter template. No dataset or licence. Replace it.
- Starting question: interpretive, a placeholder to be replaced.
- Observed, reanalysed or modelled data: none yet.

This sketch cannot yet show anything about real weather. It has no observations and no real place or time.
